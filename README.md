# ✨ Why Quill?

Quill is designed as a **single productivity workspace** instead of a collection of disconnected utilities.

It brings together:

- 🌍 **Text and voice translation**
- 🎙️ **Speech-to-text and speech-to-speech translation**
- 📄 **Multi-page document translation**
- 🧩 **PDF, image, Word, and Excel utilities**
- 🛠️ **Everyday calculation and conversion tools**
- 🕘 **Account-synced activity history**
- ⭐ **Favorites and saved translations**
- 🔔 **Notifications**
- ⚙️ **Detailed application settings**
- 🔐 **Authentication and account management**
- 📥 **Export and download workflows**

# 🌍 Translation Workspace

Quill provides a **unified translation interface** for text and speech.

## Supported Translation Modes

| Mode | Description |
|---|---|
| **Text → Text** | Translate written text into another language |
| **Text → Speech** | Translate text and generate spoken audio |
| **Speech → Text** | Record speech and convert it into text |
| **Speech → Speech** | Record speech, translate it, and generate translated audio |

## Translation Capabilities

- 🌐 **25 supported languages**
- 🔎 **Automatic source-language detection**
- 🔄 **Source/target language swapping**
- ⚡ **Automatic translation while typing**
- 🕘 **Translation history**
- 📝 **Formatting preservation**
- 🎨 **Translation style controls**
- 🗣️ **Formality controls**
- 🚀 **Translation speed settings**
- 📋 **Copy translated text**
- 📥 **Import `.txt`, `.md`, and `.csv`**
- 🎤 **Voice recording directly from the browser**
- 🔊 **Audio playback for generated speech**
- ⚙️ **Engine selection**
- 🔁 **Fallback translation services**
- 🌏 **Localized handling of remaining Latin terms for non-Latin languages**
- ⭐ **Save translations to favorites**

## Supported Languages

Quill supports the following language workflows:

**English, Hindi, Spanish, French, German, Italian, Portuguese, Russian, Japanese, Korean, Chinese, Arabic, Turkish, Dutch, Polish, Swedish, Indonesian, Vietnamese, Ukrainian, Marathi, Tamil, Telugu, Malayalam, Bengali, and Gujarati.**

# 🎙️ Voice Translation

Quill includes a complete **browser-to-backend speech pipeline**.

## Speech Workflow

```text
🎤 Microphone
      ↓
🌐 Browser MediaRecorder
      ↓
📤 Uploaded Audio
      ↓
⚙️ FFmpeg / FFprobe
      ↓
🎵 Normalized WAV
      ↓
🧠 Speech Recognition
      ↓
🌍 Translation Engine
      ↓
🔊 Edge TTS / gTTS
      ↓
✅ Translated Audio
```

# ⚡ Local Development

Follow the steps below to run **Quill locally**.

## 1. Clone the Repository

```bash
git clone https://github.com/Aarush005coder/Quill.git
cd Quill
```

---

## 2. Frontend Setup

Open a terminal and navigate to the frontend:

```bash
cd frontend
```

Install the required dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The frontend will be available at:

**http://localhost:3000**

### Production Build

To create an optimized production build:

```bash
npm run build
```

---

## 3. Backend Setup

Open a **second terminal** and navigate to the backend:

```bash
cd backend
```

Create a Python virtual environment:

```bash
python -m venv venv
```

### Windows

Activate the virtual environment:

```powershell
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Database Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Create Admin User

```bash
python manage.py createsuperuser
```

### Start Django Server

```bash
python manage.py runserver
```

The backend API will be available at:

**http://127.0.0.1:8000**

# 🧠 Translation Engine Strategy

Quill supports multiple translation services with fallback strategies to improve reliability.

```text
🌍 Requested Translation Engine
            ↓
      Primary Service
            ↓
        If Failed
            ↓
       🔤 MyMemory
            ↓
        If Failed
            ↓
        🌐 Lingva
            ↓
        If Failed
            ↓
     🔄 LibreTranslate
            ↓
        If Failed
            ↓
      🌍 Google
```

This architecture helps prevent a failure from a single translation provider from breaking the complete translation workflow.

# 🧠 Speech Processing Strategy

Quill normalizes browser-recorded audio before speech recognition.

```text
🎤 Browser Audio
      ↓
⚙️ FFmpeg Decode
      ↓
🎚️ Mono Audio
      ↓
⏱️ 16 kHz Sample Rate
      ↓
🎵 PCM WAV
      ↓
🔇 Silence / Signal Analysis
      ↓
🧠 Speech Recognition
```

Generated speech follows:

```text
🌍 Translated Text
      ↓
🗣️ Edge TTS
      ↓
If Failed
      ↓
🔊 gTTS Fallback
      ↓
🎵 MP3
      ↓
💾 Stored Media
      ↓
🔗 Audio URL
```
