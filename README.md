# ✨ Why Quill?

Quill is designed as a **single productivity workspace** instead of a collection of disconnected utilities.

It brings together:

- 🌍 **Text and voice translation**
- 🎙️ **Speech-to-text and speech-to-speech translation**
- 📄 **Multi-page document translation**
- 🧩 **PDF, image, Word, and Excel utilities**
- 🛠️ **Everyday calculation and conversion tools**
- 🕘 **Account-synced activity history**
- ⭐ **Favorites and saved translations**
- 🔔 **Notifications**
- ⚙️ **Detailed application settings**
- 🔐 **Authentication and account management**
- 📥 **Export and download workflows**

# 🌍 Translation Workspace

Quill provides a **unified translation interface** for text and speech.

## Supported Translation Modes

| Mode | Description |
|---|---|
| **Text → Text** | Translate written text into another language |
| **Text → Speech** | Translate text and generate spoken audio |
| **Speech → Text** | Record speech and convert it into text |
| **Speech → Speech** | Record speech, translate it, and generate translated audio |

## Translation Capabilities

- 🌐 **25 supported languages**
- 🔎 **Automatic source-language detection**
- 🔄 **Source/target language swapping**
- ⚡ **Automatic translation while typing**
- 🕘 **Translation history**
- 📝 **Formatting preservation**
- 🎨 **Translation style controls**
- 🗣️ **Formality controls**
- 🚀 **Translation speed settings**
- 📋 **Copy translated text**
- 📥 **Import `.txt`, `.md`, and `.csv`**
- 🎤 **Voice recording directly from the browser**
- 🔊 **Audio playback for generated speech**
- ⚙️ **Engine selection**
- 🔁 **Fallback translation services**
- 🌏 **Localized handling of remaining Latin terms for non-Latin languages**
- ⭐ **Save translations to favorites**

## Supported Languages

Quill supports the following language workflows:

**English, Hindi, Spanish, French, German, Italian, Portuguese, Russian, Japanese, Korean, Chinese, Arabic, Turkish, Dutch, Polish, Swedish, Indonesian, Vietnamese, Ukrainian, Marathi, Tamil, Telugu, Malayalam, Bengali, and Gujarati.**

# 🎙️ Voice Translation

Quill includes a complete **browser-to-backend speech pipeline**.

## Speech Workflow

```text
🎤 Microphone
      ↓
🌐 Browser MediaRecorder
      ↓
📤 Uploaded Audio
      ↓
⚙️ FFmpeg / FFprobe
      ↓
🎵 Normalized WAV
      ↓
🧠 Speech Recognition
      ↓
🌍 Translation Engine
      ↓
🔊 Edge TTS / gTTS
      ↓
✅ Translated Audio

### Voice features

• Browser microphone recording
• WebM / OGG / MP4 audio support
• FFmpeg-based audio conversion
• 16 kHz mono WAV normalization
• Speech recognition
• Automatic language recognition
• Neural voice generation
• gTTS fallback
• Audio playback
• Speech-to-speech history entries

# ⚡ Local Development

**1. Clone the repository**

git clone https://github.com/Aarush005coder/Quill.git
cd Quill

**2. Frontend setup**

- cd frontend
- npm install
- npm start

Frontend:

- http://localhost:3000
- Production build
- npm run build

**3. Backend setup**

Open a second terminal:

- cd backend
- python -m venv venv

Windows

- venv\Scripts\activate
- Install dependencies
- pip install -r requirements.txt
- Run migrations
- python manage.py migrate
- Start Django
- python manage.py runserver

Backend:

http://127.0.0.1:8000

# 🔑 Environment Variables

Never commit production secrets to GitHub.

### Frontend

**Create:**
frontend/.env

**Example:**

**REACT_APP_API_URL=http://127.0.0.1:8000/api**
For production, replace the local URL with the deployed backend API URL.

### Backend

**Create:**
backend/.env

**Example:**

- SECRET_KEY=your-secret-key
- DEBUG=True
- ALLOWED_HOSTS=localhost,127.0.0.1
- BACKEND_URL=http://127.0.0.1:8000
- FRONTEND_URL=http://localhost:3000

- DB_NAME=quill
- DB_USER=postgres
- DB_PASSWORD=your-db-password
- DB_HOST=localhost
- DB_PORT=5432

- GOOGLE_CLIENT_ID=
- GOOGLE_CLIENT_SECRET=

- GITHUB_CLIENT_ID=
- GITHUB_CLIENT_SECRET=

- BREVO_SMTP_HOST=smtp-relay.brevo.com
- BREVO_SMTP_PORT=587
- BREVO_SMTP_USE_TLS=True
- BREVO_SMTP_LOGIN=
- BREVO_SMTP_KEY=
- DEFAULT_FROM_EMAIL=Quill <your-email@example.com>

- GROK_API_KEY=
- DEEPL_API_KEY=
- MICROSOFT_TRANSLATOR_KEY=
- MICROSOFT_TRANSLATOR_REGION=eastus

# 🗄️ Database

Quill uses PostgreSQL for persistent application data.
Make sure PostgreSQL is running before starting Django.

Then:

• python manage.py makemigrations
• python manage.py migrate

**Create an admin account:**
• python manage.py createsuperuser

---

# 🎙️ FFmpeg Setup

Voice translation requires FFmpeg and FFprobe.
After installing FFmpeg, verify:

• ffmpeg -version
• ffprobe -version

The backend also supports explicit FFmpeg path configuration and can automatically detect common Windows installation layouts.

# 🌐 Deployment

## Frontend

The React frontend is Vercel-ready.

### Typical settings:

• Framework: Create React App
• Root Directory: frontend
• Build Command: npm run build
• Output Directory: build
• Install Command: npm install

### Production environment variable:

**REACT_APP_API_URL=https://your-backend-domain.com/api**
Do not use http://127.0.0.1:8000/api in production.

## Backend

The Django backend should be deployed on a Django-compatible server/platform with:

• PostgreSQL
• Environment variables
• Persistent media/storage strategy
• FFmpeg where required
• HTTPS
• CORS configuration
• Static file handling
• Production WSGI/ASGI configuration
